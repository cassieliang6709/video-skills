# 画面规范与组件

## 版式（1920×1080，30fps）
- 左上 y<80 章节标题；底部 y>950 字幕。**内容只放在 y 90–940**，元素之间不重叠、不压字幕、不出界。
- 代码字号 ≥ 24，正文 ≥ 28；同屏代码 ≤ 10 行，超过就分阶段换面板（Fade until）。
- 一屏只强调一件事；用黄色高亮当前句提到的元素，其他元素降低不透明度。
- 每个张量旁边标形状。全片统一配色：Q=C.q 蓝、K=C.k 绿、V=C.v 橙、强调=C.accent 紫、错误/复制=C.red、高亮=C.yellow。

## 节拍同步
`const { beat, t, on, span, len } = useBeat()`（src/lib/beat.tsx）
- `beat` 当前句；`t(b)` 第 b 句开始后的帧数（之前为负）；`on(b, dur=18, delay=0)` 0→1 缓动；
  `span(a, b)` a 句淡入 b 句淡出；`len(b)` 第 b 句帧数。
- 画面随句切换；同一句里的多步动画用 `on(b, dur, delay)` 按 `len(b)` 比例排时间。

## 组件（src/lib/ui.tsx）
- `CodePanel`：lines = [{code, at: 句号, delay?, out?}]，到点打字出现，当前句的行高亮，out 是黄色真实输出。
- `Matrix`：数值矩阵，支持 rowLabels/colLabels、hlRows/hlCell 高亮、mask（如 causal -∞）、reveal 逐格出现。
- `Fade`、`Tag`、`H`（高亮文字）。
- `Tex`：KaTeX 公式，`<Tex size={40}>{String.raw`c_t^{KV} = W^{DKV} h_t`}</Tex>`。SVG 里的 `<text>` 和普通字符串不走 KaTeX，`^`、`_` 会原样显示，公式一律用 Tex。
- 画面写法参考 `references/example_scenes.tsx`（MLA 那期的 4 个场景：漏斗压缩、分屏对比、RoPE 钟表旋转、分段色条）。
  那份用的是旧框架（帧数 + `Appear`），只借鉴构图和动画思路，节拍仍用 useBeat，不要直接复制。
- 需要新组件就写在该章的 `src/chapters/chN_parts.tsx`，通用性强的再提到 lib。

`node tools/stills.mjs chN && tools/sheet.sh chN`，用 Read 看 `out/check/chN/sheet_*.jpg`
（每格 = 每句 80% 处的画面）。检查：重叠/压字幕/出界、画面与旁白是否对应、"画："说明是否实现。

## 算法类主题（没有张量）
- 用 `src/lib/algo.tsx`：数组 `Cells`、dict/set `DictBox`、trace 表 `Table`、题面/结论 `Card`、行内代码 `M`、对错 `Mark`、`ent(dict)`。
- 配色：当前元素 tone "hl"（C.yellow）、已走过的 [0,i) "accent"、查到/正确 "ok"（C.k）、错误 "bad"（C.red）、无效值 "dim"。
- 尺寸（nudgecode 数组章用户确认过"放大一号"）：格子 cell 110–130，CodePanel fontSize ≈32、宽 900–980，Table fontSize 30–34。
  单行超过 ~55 字符的代码在 fontSize 32 会被面板截断，要缩到 28 或加宽面板，拼图里检查。
- 常用布局：代码面板在左（left 60），状态区在右（left ≈1060）；按 `if (beat <= k) return …` 分场景。
- agent 不要自己编屏幕上的文件名、命令（如 `$ python xxx.py`）；只显示 tutorial.py 里真有的东西。

## 整片视觉与封面统一（2026-10-24 用户要求"整个视频的图案参考封面那种"）
- 章节标题卡已改为封面同款：纯黑底、黄底黑字章号、白色粗体大标题（`beat.tsx`）。
- 每章至少一个"封面式"关键帧：一句钩子大字（≥96px）+ 黄底黑字高亮一个词或数字，配一个大视觉物（栈帧、代码、巨大数字）。
  用 `Cover.tsx` 里的 `Hl` / `BigNumber` / `CodeVisual`，和封面同一套配色 `K`（黄 #ffd400、红 #ff5c5c、青 #9fe3ff）。
- 反常数字、对比结论用大字号单独占一屏（例："快 3 倍""50 亿 → 10 万"），不要埋在表格里。
- 一屏只强调一件事；强调色只用黄，错误/危险用红，其余元素降不透明度。
- 转场可点名用：引导物、嵌套缩小、明暗背景切换、数字滚动（见 plotome-lessons.md）。

## 截帧学到的画面（2026-10-24，比特新语《脑内擂台》8 帧、Redknot-乔红《SSD 的原理》11 帧，只看不存）
**Redknot：一个物体，镜头一层层往里推**
- 浅灰无缝背景加柔和阴影，画面正中只有一个物体。开头是整块 SSD 的写实模型，结尾回到真实产品照片。
- 缩放阶梯：整块 SSD → 一颗芯片 → 一个存储单元方块（旁边一个圆形徽章写"10 years"）→ 晶体管剖面 → 一排排单元（QLC 4bit）→ 字线阵列 → 3D 的 Block。每一层都是上一层的放大。
- 状态用"数得出来的东西"表示：电荷是一颗颗粉色小球，存 1 还是存 0 一眼能看出来；关键电压直接写大字"5V / 0V"。
- 标注很少：细引线，加中英双语小字（栅极 Gate、N 沟道 N-Channel、衬底 Substrate）；用虚线框圈出正在讲的那一排。
- 对比用左右两格，同一个单元并排放：左边"1"，右边打叉。
**比特新语：黑底发光角色，一个角色对应一个概念**
- 纯黑底，金色、青色的发光线条小人站在擂台光圈里。每个概念一个角色、一种颜色，全片不换。讲到谁，谁亮，别的变暗。
- 小节卡是一行金色小字，比如"上场 · 多巴胺的打法"。
- 关键句不放在底部字幕里，而是居中用大号衬线字单独出现，一个词换颜色强调（"是它打的""还有一个对手在等"）。
- 高潮处粒子爆开；结尾换成一个意象画面：人头剪影里是城市灯光，配"在你手里"。
**落到我们的片子**
1. **一个"物" + 缩放阶梯**：系统篇的"物"就是那张贯穿全片的物理图（终端窗口 → 进程 → CPU 和"执行到哪了"的记录 → 一条指令）。每一层都从上一层放大进去，不切到无关的新画面。
2. **一个角色一种颜色，全片固定**：比如每个进程一个固定颜色的方块，内核固定一种颜色，信号固定一种颜色。讲到谁，谁高亮，其余降低不透明度。
3. **状态做成数得出来的东西**：683 个进程画成 683 个小格；缺页一次亮一格；pending 信号画成一个红点，来三个也只亮一个。
4. **左右对比格**：fflush 前后、wait 前后、屏蔽前后，同一个东西并排放。
5. **关键句居中大字**（≥96px，用 `Hl` 标一个词）：每章一次，放在结论句上。平时字幕照常放底部。
6. 标注只用细引线加中英小字；正在讲的部分用虚线框圈出来。

## 自检盲区与拼图检查要点（2026-11 补）
- `stills.mjs` 每句只截 80% 处一帧：80% 之后才出现的元素（丢包红叉、晚出的大字、最后一步动画）截不到；关键元素要在 80% 前出现并停留到句末，或单独截那一刻确认。
- 淡出的元素（丢掉的包、被替换的标签）在截图里常常已经看不见：重要的状态（红叉、"丢了"）要停留到句末。
- 拼图逐格看：①压字幕（底部 ~150px 留给字幕）②出界/截断（长代码行、长标签、超宽数字条）③重叠（标签压曲线、刻度被圆点挡）④只占上半屏 ⑤正文 < 28px ⑥封面式大字和该句字幕说同一句 ⑦`<Hl>` 之类标签被当文字显示 ⑧示意数没标"示意"。
- 按比例画会小到看不见的东西（64 KB 对 12.5 MB）：放大并注"不按比例"。
- 隐私：真实命令输出里的 MAC、公网 IP、局域网地址打码或换示例值；`127.0.0.1` 和代理的 `198.18.x.x` 可以显示。
